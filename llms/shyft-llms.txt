# Shyft Customer API

> Shyft is a mobile-first workforce management platform for hourly and shift-based teams: employees swap shifts, message teammates, set availability, and manage schedules from their phone. The Shyft Customer API backs the Shyft mobile apps (iOS, Android), the web app, and the Manager Dashboard. It is a resource-oriented REST/JSON API secured with HTTP Bearer (JWT) tokens.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public Redoc documentation and the harvested OpenAPI. Method: generated. Generated: 2026-07-21.

## API
- [Shyft Customer API docs (Redoc)](https://customer-api-doc.myshyft.com/): 234 operations across authentication, users, locations, availabilities, schedules, shifts, channels, chats, posts, notifications, departments, EWA (earned wage access), subscriptions and products.
- Authentication: HTTP Bearer JWT (`Authorization: Bearer <token>`); public auth endpoints use a noauth scheme. A custom `Session-Uukey` header accompanies most authenticated calls.
- Base path: `/api`. Version: 1.0.0. Pagination: page-based via `per_page`. Tracing: `x-request-id` response header. Roles are gated by `user_role` vs `admin_role` path segments.
